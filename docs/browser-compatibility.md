# 浏览器兼容性

生产程序使用普通 Google Chrome 和 MV3 扩展，通过标准网页控件操作。不要把日常 Chrome 资料复制进项目，也不要启用 DevTools／CDP 来控制真实 BOSS 页面。

旧调试适配器在某些网页版本中曾遇到导航回退到 `about:blank`。当前默认程序已采用普通浏览器扩展，旧适配器仅保留用于本机测试与诊断；不禁用网站检查或更改浏览器指纹。

如果专用浏览器仍为空白，先核对控制台的扩展连接，再点击“打开浏览器 / 扫码登录”。扩展管理页无法自动打开时，在该专用浏览器地址栏输入 `chrome://extensions/`。网页登录、验证码、平台限制仍按页面提示处理。

网页结构可能变化。本机 fixture 测试通过不能代替当前真实网页兼容性检查；报告问题时只提交匿名错误码和复现步骤。
