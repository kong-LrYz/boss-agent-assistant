# 验证范围

测试使用虚构岗位、临时数据目录和本机网页，不需要 BOSS 账号。生产连接采用普通 Google Chrome 与 MV3 扩展；测试 Chromium 与个人登录目录隔离。

完整本机验证命令：

```sh
npm ci
npm run setup
BOSS_NATIVE_SMOKE=1 npm test
```

发布前运行完整本机回归，并在修改后核对运行与测试源文件 SHA256。最新跨平台结果见 [GitHub Actions](https://github.com/kong-LrYz/boss-agent-assistant/actions)。

主要覆盖：

- BOSS 原生岗位和地区目录、四种岗位类型、更换岗位默认规则、原有自定义配置保留。
- 独立的公司联系与附件送达目标、已完成目标、重启续跑、同公司不同岗位处理。
- 设置保存回读、迟到响应、按钮处理中状态、停止与关闭控制台行为。
- 收件人、岗位 ID、实际地址与会话绑定；错误或过期页面不会授权发送。
- 发送意图先持久化、实际成功回执、未确认结果隔离与禁止自动重放。
- 单岗页面变化自动跳过、有限失败缓存、新信息触发重新读取；登录、验证码、连接和平台限制保留全局处理。
- 扩展配对、唯一工作标签、一次性操作许可、本机 HTTPS fixture 的完整生命周期。
- 读取重试和真实限流恢复预算、无人工延迟调度、附件队列轮转。
- 日志容量、事件截断、诊断保留与磁盘写入失败恢复。
- 安装入口、校验下载、Unicode／空格路径、依赖复用和并发安装保护。

GitHub Actions 在 Linux、macOS 和 Windows 上运行本机 fixture 测试；安装入口另做 shell／PowerShell 语法检查。它们不证明各系统的真实 BOSS 页面、登录或长期投递已经验证。

本机测试、历史短批次测量和真实持续投递是不同证据。网站改版、网络、账号状态、附件发送权限都会影响实际结果；不能根据本机仿真承诺长期吞吐或附件必定送达。

公开文件不附带任何使用者的聊天、简历、目标公司、账号计数、浏览器资料、截图、配对密钥或原始运行日志。测试证书及私钥仅用于独立临时 fixture，不写入系统或个人浏览器信任库。
